```
가족·지인에게 카카오톡으로 옵트인 링크를 직접 보내 모집했습니다. 유료 테스트 업체는 쓰지 않았습니다. 안드로이드 사용자만 골라 부탁했고, 링크→'테스터 되기'→설치 순서를 문구로 안내했습니다. 최대 29명이 설치했고 14일 내내 유지된 인원은 12명입니다.
```

**Q3 참여도** (217자)

```
테스터는 실사용자와 같은 목적(법원 자동차 경매 물건 검토)으로 물건 목록·상세·종합 리포트·경매 달력·예측 적중률 화면을 둘러봤습니다. 앱은 방문 기록을 수집하지 않아(데이터 안전 '수집 없음') 기능별 사용량은 알 수 없고, 참여도는 카카오톡 답장과 설치 유지 인원으로 판단했습니다. 실사용자는 입찰 직전 특정 물건을 깊게 보는 반면 테스터는 넓게 둘러보는 차이가 있을 것으로 봅니다.
```

**Q4 의견 요약(오너 보완)** (185자)

```
의견은 카카오톡 답장과 이메일로 받았습니다. 주요 의견: ①{테스터 의견 1} ②{테스터 의견 2} ③{테스터 의견 3}. 테스트 기간 중 반영: 끝난 경매에 D-DAY 표시가 남던 문제 수정, 판정 색·문구를 목록·상세·리포트에서 통일, 리포트 오차 표기를 전체 평균과 유형별로 분리, 큰글씨 모드 개선(9/12~9/25 배포).
```

**③ 준비 근거(참고)** (153자)

```
실제 낙찰 결과와 대조한 예측 적중률을 앱 안에서 공개하고 있으며(검증 표본·평균 오차 실시간 표시), 테스트 기간 크래시 보고 0건, 가입·결제·광고·개인정보 수집이 없어 정책 리스크가 낮습니다. 대상은 한국, 무료, 출시 후에도 매일 자동 갱신과 주간 개선을 계속합니다.
```

**②-1 주요 대상** (170자)

```
한국에서 법원 자동차 경매로 차를 사려는 실수요자입니다. 특히 입찰가를 얼마로 써야 할지 근거가 필요한 분, 여러 물건을 빠르게 훑어 검토할 물건만 추리려는 분, 포터·봉고 등 상용차가 필요한 자영업자입니다. 만 18세 이상 성인 대상이며, 경매 입찰은 법원에서 이뤄지고 앱 안에서는 입찰할 수 없습니다.
```

**②-2 제공 가치** (184자)

```
대법원 법원경매정보의 자동차 물건을 감정가·유찰 이력·사고정보·주행거리와 동급 중고차 시세로 대조해 물건마다 예상 낙찰가와 입찰 상한가를 계산합니다. 과거 실제 낙찰 결과와 대조한 오차·적중률을 앱 안에 그대로 공개하고, 표본이 부족하면 숫자를 만들지 않고 '미산출'로 표시합니다. 가입·결제·광고·개인정보 수집 없이 무료입니다.
```

**②-3 첫해 예상 설치 수(라디오)**: `0~1만` — 국내 법원 자동차 경매 실수요자 대상의 틈새 도구, 광고 집행 없음. 부풀리지 않는다.

**③-1 테스트로 바꾼 것** (222자)

```
테스트 기간(9/12~9/25) 중 발견한 것을 고쳐 배포했습니다. 끝난 경매에 'D-DAY 입찰' 표시가 남던 문제 수정, 판정 색과 문구를 목록·상세·리포트에서 하나의 기준으로 통일, 오차 표기를 '전체 평균'과 '이 유형'으로 분리해 과대 표시 방지, 시세 미산정 물건의 안내 문구에서 사용자에게 없는 버튼 언급 제거, 침수·시동불가 물건은 리포트 첫 문장에 판정을 명시, 큰글씨 모드 보완.
```
