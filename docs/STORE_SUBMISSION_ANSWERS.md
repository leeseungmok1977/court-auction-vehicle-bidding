## 1. v1 광고 정책 — 확정 및 재활성화 시 주의

**결정: v1은 광고 없이 출시.** 서버 설정 `adsense_client`를 비워 광고 스크립트 자체가 렌더되지 않습니다(코드는 남아 있으나 조건 미충족으로 출력 0).

**왜 껐는가**
- v1 목적은 수익이 아니라 **지표 검증**(설치·리텐션·화면 체류). 광고는 도움이 안 되고 초기 UX만 해침.
- 순수 TWA는 AdMob 불가 → AdSense뿐인데 **eCPM이 낮아** DAU 수백 규모에선 수익이 미미.
- 엔카·케이카 파생 시세가 실린 페이지의 광고 수익화는 **AdSense 정책 저촉 소지**. 계정 정지 시 복구가 거의 불가하고 다른 GET 시리즈 앱까지 영향(비대칭 리스크).
- **v2는 AdSense가 아니라 AdMob**(네이티브 셸)이므로, AdSense 승인은 v1·v2 어느 경로에도 없음.

**AdSense 심사 처리**: 사이트가 "게재 가능 여부 검토 중"이었으므로, 콘솔 **사이트 → naechaget.co.kr → 삭제**로 **자진 철회**할 것. 코드를 지운 채 심사가 진행되면 "코드를 찾을 수 없음"으로 실패하는데, 계정 제재는 아니지만 자진 철회가 더 깔끔함.

> ⚠️ **재활성화 시 반드시 갱신**: `adsense_client`에 값을 다시 넣으면 광고가 즉시 되살아납니다. 그 순간 아래 §2·§3·§4의 "광고 없음" 신고가 **허위가 되므로**, Play 콘솔의 **데이터 안전·광고 포함·콘텐츠 등급**을 같이 갱신해야 합니다.

## 2. 데이터 안전 (Data Safety)

### 2.1 개요 질문 — **확정(2026-09-11, Google 공식 목록 대조 후 제출 완료)**

| 콘솔 문항 | 답 | 근거 |
|---|---|---|
| **앱에서 필수 사용자 데이터 유형을 수집하거나 공유하나요?** | **아니요** | §2.2 전 카테고리 대조 결과 해당 없음 |
| 전송 중 데이터 암호화 | (해당 없음 — 수집 없음) | 전 구간 HTTPS이긴 함 |
| 독립적 보안 검토 / UPI 결제 인증 배지 | 아니오(선택) | 외부 보안감사 없음 / 인도 전용 |

**스토어 표시 결과**: `선언된 데이터 수집 없음` + `제3자와 공유되는 데이터 없음` 배지.

> **기기에만 저장되는 데이터는 '수집'이 아닙니다.** 즐겨찾기·메모·최종입찰가(localStorage)는 기기를 떠나지 않으므로 신고 대상이 아닙니다(Google 명시 기준).

### 2.2 전 카테고리 대조 (Google 필수 데이터 유형 목록 기준)

| 카테고리 | 우리 앱 | 해당 |
|---|---|---|
| 위치(대략/정확) | 위치 권한 미사용, **IP로 위치를 추론하지 않음** | ❌ |
| 개인정보(이름·이메일·사용자ID·주소·전화 등) | 계정 기능 없음(users 행수 0) | ❌ |
| 금융정보(결제수단·구매내역) | 결제 없음 | ❌ |
| 건강·메시지·사진·오디오·파일·캘린더·연락처 | 전부 미사용 | ❌ |
| 앱 활동(상호작용·검색기록·설치앱·**메모**) | 메모는 localStorage 전용, 서버 미전송 | ❌ |
| 웹 탐색 기록 | 수집 안 함 | ❌ |
| 앱 정보 및 성능(비정상종료·진단) | 크래시 리포팅 도구 없음 | ❌ |
| 기기 또는 기타 ID | 예시가 IMEI·MAC·Widevine·Firebase ID·광고 ID — **IP는 목록에 없음**. 광고 비활성·제3자 스크립트 0건 | ❌ |

**IP(nginx 접근로그, 14일)를 신고하지 않는 근거**: Google 목록에서 IP가 언급되는 곳은 **위치 카테고리뿐**이며, 문구가 *"IP 주소 등을 통해 **추론된** 대략적인 위치를 공개해야 한다"* 이다. 공개 대상은 IP 자체가 아니라 **추론된 위치**인데, 우리는 IP를 위치로 변환·사용하지 않는다. 또한 IP는 '기기 또는 기타 ID'의 예시(IMEI·MAC·Widevine·Firebase·광고ID)에 없다. 접근로그는 분석 도구에 투입·프로필 연결·외부 제공이 전혀 없고 14일 후 자동 삭제되는 **웹서버 인프라 로그**다. 이 기준을 적용하지 않으면 HTTP로 동작하는 모든 앱이 신고 대상이 된다.

### 2.3 신고하지 않는 것 (근거 기록)

| 항목 | 왜 신고 안 하나 |
|---|---|
| 즐겨찾기·메모·최종입찰가 | 기기 로컬 저장, 서버 전송 없음 → '수집' 아님 |
| 위치·카메라·연락처·알림 | 권한 자체를 요청하지 않음(코드상 0건) |
| 이름·이메일·사용자 ID | 계정 기능 없음(users 행수 0) |
| 결제·구매 내역 | 결제 기능 없음 |
| 광고 식별자 | **광고 비활성**(제3자 스크립트 0건) |

| 추가 기능 | 데이터 안전 추가 신고 | 그 밖에 바뀌는 것 |
|---|---|---|
