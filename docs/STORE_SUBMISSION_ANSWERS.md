## 1. ⚠️ 제출 전 반드시 결정할 것 — v1 광고 유지 여부

**"v1은 광고 없음"이라는 전제는 현재 사실과 다릅니다.** AdSense가 이미 송출 중입니다.

| | 시나리오 A — 광고 유지(현 상태) | 시나리오 B — 광고 끄고 출시 |
|---|---|---|
| 데이터 안전 | **수집·공유 있음**으로 신고 | **수집 없음**에 가까움 |
| 콘텐츠 등급 '광고 포함' | 예 | 아니오 |
| 정책 리스크 | 제3자(엔카·케이카 파생) 시세가 실린 페이지를 광고로 수익화 → AdSense 정책 저촉 소지 | 없음 |
| v1 목적(지표 검증) 부합 | 낮음(수익 미미) | 높음 |

> 끄는 방법: 서버에서 `adsense_client` 설정값을 비우면 템플릿 조건이 꺼져 스크립트가 사라집니다(코드 수정 불필요).

**아래 §2·§3은 두 시나리오 답을 모두 제공합니다. 결정한 쪽만 콘솔에 옮겨 적으세요.**

## 2. 데이터 안전 (Data Safety)

### 2.1 공통 — 개요 질문

| 콘솔 문항 | 답 | 근거 |
|---|---|---|
| 전송 중 모든 사용자 데이터가 암호화되나요? | **예** | 전 구간 HTTPS |
| 사용자가 데이터 삭제를 요청할 수 있나요? | **해당 없음 / 아니오** | 서버에 사용자 데이터 자체를 저장하지 않음. 기기 로컬 데이터는 앱 삭제·브라우저 데이터 삭제로 사용자가 직접 제거 가능 — 개인정보처리방침에 이 문구를 명시해 둘 것 |
| 독립적 보안 검토를 받았나요? | 아니오(선택 항목) | — |

> **기기에만 저장되는 데이터는 '수집'이 아닙니다.** 즐겨찾기·메모·최종입찰가(localStorage)는 기기를 떠나지 않으므로 신고 대상이 아닙니다. 이건 Google이 명시한 기준입니다.

### 2.2 시나리오 A — 광고 유지(현재 상태)

**"앱에서 사용자 데이터를 수집하거나 공유하나요?" → 예**

| 데이터 유형 | 수집 | 공유(제3자) | 필수/선택 | 목적 | 근거 |
|---|---|---|---|---|---|
| **기기 또는 기타 ID** | ✅ | ✅ (Google) | 필수 | 광고 또는 마케팅 | AdSense가 광고 쿠키·식별자 사용 |
| **앱 활동 → 앱 상호작용** | ✅ | ✅ (Google) | 필수 | 광고 또는 마케팅, 분석 | 광고 게재·측정에 페이지 조회가 전달됨(보수적 신고) |
| **위치 → 대략적인 위치** | ✅ | ✅ (Google) | 필수 | 광고 또는 마케팅 | 앱이 위치 권한을 쓰진 않지만 AdSense가 **IP로 대략적 위치를 추론**함(보수적 신고) |

- 세 항목 모두 **"사용자가 수집을 선택 해제할 수 없음"**(필수)로 표기 — 광고가 기본 노출이므로.
- ⚠️ **확인 권장**: Google이 게시자용으로 안내하는 *광고 데이터 공개 가이드*와 대조해 유형을 최종 확정하세요. 위 3종은 광고 SDK 사용 앱의 **보수적 표준 조합**입니다.

### 2.3 시나리오 B — 광고를 끄고 출시

**"앱에서 사용자 데이터를 수집하거나 공유하나요?" → 아니오**

- 계정 없음 · 서버 개인정보 저장 없음 · 기기 권한 0 · 제3자 SDK 없음.
- 남는 건 **nginx 접근로그(IP, 14일)** 뿐 → §2.4 판단에 따름.

### 2.4 판단이 필요한 단 하나 — 웹서버 접근로그

nginx가 IP를 14일 보존합니다. Google의 데이터 안전 기준에서 **웹서버 운영 로그**는 회색지대입니다.

- **신고 안 함**(일반적 해석): 보안·운영 목적으로만 쓰고, 다른 목적 전용·제3자 전송이 없으며, 사용자 프로필과 연결하지 않음.
- **신고 함**(보수적): "기기 또는 기타 ID" 수집 / 목적 "앱 기능, 보안 및 사기 방지" / 공유 없음.

> **권장: 보수적으로 신고(후자).** 과다 신고는 위반이 아니고, 과소 신고는 위반입니다. 시나리오 B를 택하더라도 이 한 줄 때문에 "수집함 → 기기 또는 기타 ID(보안 목적, 공유 없음)"로 신고하는 편이 안전합니다.
> ※ 이 항목은 제가 **확신할 수 없는 유일한 부분**입니다. 그대로 따르기보다 Play 정책 문서에서 'server logs' 예외를 한 번 확인하시길 권합니다.
