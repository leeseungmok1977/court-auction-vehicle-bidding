# 준법·리스크 검토 (compliance-officer)

> 코드가 아닌 리스크 검토·로드맵. **최종 법적 판단은 사람(변호사)에게 위임.** 여기서 "합법"을 단정하지 않는다.
> billing 활성화·유료 시세 노출은 아래 완화방안 충족 전까지 **불가**.

## 1. 데이터 소스별 리스크

| 소스 | 용도 | 리스크 | 심각도 | 완화방안 |
|---|---|---|---|---|
| **SK엔카 시세** | 시세 중앙값 | robots.txt 전면 Disallow. 검증용 소량 수집과 **상용 재배포는 다름** | **높음** | 유료 서비스에 엔카 시세 그대로 노출 금지. 대체 소스(아래 §2)로 전환 필요 |

## 2. 대체 시세 소스 로드맵 (엔카 의존 탈피)
1. **(a) 자체 축적 낙찰가 DB** — 우리가 합법적으로 모은 실제 낙찰가로 예측(백테스트 기반). **가장 안전**, 데이터 축적할수록 정확. → 우선 투자.
2. **(b) 공식 제휴/공개 API** — 엔카·케이카·KB차차차 제휴 또는 공개 시세 API 조사.
3. **(c) 공공데이터** — 국토부 자동차 이전등록/자동차관리정보 등 활용 가능성 조사.

## 3. 개인정보(회원 DB) 체크리스트
- [ ] 최소수집(이메일 등), 수집·이용 동의, 목적 명시
- [ ] 비밀번호 해시(bcrypt 등)·전송 암호화(HTTPS)
- [ ] 보관기간·파기 정책, 접근통제
- [ ] 개인정보처리방침 게시

## 4. 전자상거래 표시의무 체크리스트
- [ ] 사업자정보(상호·대표·사업자번호·주소·연락처)
- [ ] 이용약관·개인정보처리방침·환불규정
- [ ] 결제 전 과금 조건 고지, 청약철회 안내

## 5. 결론(현재)
- **감정평가서 원본 연결(뷰어)**: 저장·재배포 없이 공식 원본을 여는 현 방식은 리스크 낮음 → 진행 가능.
- **엔카/케이카 시세의 유료 노출**: §2 대체 소스 전환 또는 제휴 확인 전까지 **보류**. 무료 검증 도구로는 현 방식 유지 가능(사용자 승인 하).
- **개인 식별정보**: 유료화 전 마스킹·최소화 검토.
- 결제·회원 활성화: §3·§4 충족 + 위 시세 이슈 해소 후, 사람(변호사) 최종 확인 하에.
