# 디자인 레퍼런스 (design-critic 채점 기준)

> 패턴 학습용. 카피·이미지·코드 복제 금지. 각 항목은 **우리 대시보드에 이식할 패턴**만 추린다.
> 우리 핵심 차별점 = **예상낙찰가 ± 신뢰구간의 시각화**(가격 신뢰도). 아래 Zillow/KBB 패턴이 최우선.

## 1. 가격 신뢰도 표현 ★ (핵심 차별점)

### Zillow Zestimate
1. **점추정 + 범위 동시 표시**: 큰 추정값 아래 "range $X – $Y"를 항상 병기 — 불확실성을 숨기지 않음.
2. **정확도 투명 공개**: "median error 2.4%" 같은 실측 오차율을 노출해 신뢰 구축(= 우리 백테스트 MAE와 동일 개념).
3. **가격 히스토리 라인차트**: 시간축 위 추정값 변화. (우리: 회차별 최저매각가 저감 곡선에 적용 가능)
→ **이식**: 예상낙찰가를 `값 + (하한~상한) 범위 바`로. MAE를 "참고 정확도 ±N%"로 이미 노출 중 → 이를 **시각 밴드**로 승격.

### KBB (Kelley Blue Book)
1. **가로 범위 바 + 마커**: 낮음──[Fair Purchase Price ▼]──높음 형태로 점추정을 범위 안에 배치.
2. **색 존(zone)**: 범위 대비 현재가 위치를 색으로(좋은가/비싼가) — 우리: 최저매각가가 예상낙찰가 대비 어디인지.
3. **한 화면 한 숫자 원칙**: 핵심 값 하나를 크게, 나머지는 보조.
→ **이식**: 상세·목록에서 `최저매각가 → 예상낙찰가 → 시세중앙값`을 **하나의 가로 게이지**로. 최저가가 예상가보다 낮으면(=기회) 초록 존.

## 2. SaaS 대시보드 (정보 밀도·위계·타이포)

### Stripe (우리 채택 시스템 · DESIGN.md)
1. **thin(300) 디스플레이 + 음수 트래킹** + `ss01`, **돈=tnum 타뷸러**.
2. **인디고는 CTA·링크에만**, 본문/숫자는 딥네이비. 카드=화이트+hairline+미세 그림자.
3. **한 밴드 1개 CTA** 원칙 — 시선 분산 방지.

### Linear
1. **surface ladder + hairline로 계층**(그림자 남발 금지), 밀도 높되 정렬 엄격.
2. **키보드/자주 쓰는 동작엔 애니메이션 최소** (Emil 원칙).
3. 표는 좁은 여백·명확한 정렬로 스캔성 우선.

### Vercel
1. **모노크롬 + 절제된 강조 1색**, 여백으로 위계.
2. 빈 상태·로딩을 1급 시민으로 디자인.

## 3. 중고차 UX (Carvana / CarMax / AutoTrader)
1. **차량 카드**: 큰 사진 → 가격(대) → 핵심 스펙(연식·주행) 칩 → 보조정보. 모바일에서 카드 단위로.
2. **필터 UX**: 상단 요약 필터 바 + 결과 수 즉시 표시.
3. **사진 갤러리**: 썸네일→라이트박스, 상태 사진 강조(우리 이미 보유).
→ **이식**: 물건목록 모바일(390px)을 표 대신 **차량 카드 리스트**로 전환.

## 4. 인터랙션·디테일 (Emil Kowalski / Jakub Krehel)
1. **easing**: 진입 ease-out `cubic-bezier(0.23,1,0.32,1)`, 버튼 `:active scale(0.97)`, transform/opacity만. (적용됨)
2. **레이어드 그림자·concentric radius·focus-visible·최소 히트영역 40px**. (부분 적용)
3. **자주 이동하는 데이터 도구엔 진입 애니메이션 금지** — 마이크로 피드백만. (적용됨)

## 5. 빈 상태 / 로딩 / 오류 (Mobbin·Land-book 사례)
1. **빈 상태 = 안내문 + 행동유도 버튼**(무엇을·왜·다음행동). 방치된 "—" 나열 금지.
2. **로딩**: 스켈레톤 또는 진행바(우리 폴링 진행바 보유).
3. **오류**: 원인 + 복구행동(재시도) 제시.
