## 수정 지시 (우선순위순, 이번 라운드 적용)

1. **[데이터 시각화·최우선] 가격 신뢰구간 게이지** — KBB식 가로 바로 `최저매각가 · 예상낙찰가 · 시세중앙값`을 범위 위에 마커로. 최저매각가가 예상가보다 낮으면(=기회) 초록 존. 상세 시세카드 상단 + (가능하면) 목록/유망물건 미니 버전. → frontend
2. **[반응형·최우선] 목록·유망물건 표의 모바일 카드화** — <lg(≈1024px)에서 표를 숨기고 카드 리스트(모델·판정·예상낙찰가·최저매각가·시세·신뢰도 스택)로. 가로 스크롤 제거. → frontend
3. **[정보위계] 상세 시세카드 재배치** — 예상낙찰가(게이지 포함)를 카드 상단으로, 통계(평균가/편차 등)는 하위/보조로. → frontend
4. [빈 상태] 목록/관심 빈 상태 카드(안내+행동유도) — round 2
5. [일관성] 관심목록에 예상낙찰가·신뢰도 반영(상한가 편중 완화) — round 2
