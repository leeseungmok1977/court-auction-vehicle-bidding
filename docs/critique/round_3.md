## 회귀 원인 — 전적으로 모바일 품질 저하
데스크톱은 리포트V2로 신뢰신호·데이터시각화가 개선돼 사실상 합격선에 근접. **순회귀는 모바일에서 발생**:
- **detail_mobile**: 헤더 버튼 묶음이 `shrink-0`(비축소)로 390px 초과 → 제목 flex 아이템이 0폭으로 짜부라져 "랜드/로버/레인/지로/버/스…" 글자당 한 줄, 관심추가 버튼이 제목과 겹침. (상세 헤더에 버튼 추가하며 유발한 flex 오버플로)
- **dashboard/watchlist mobile**: 유망물건·관심목록 표가 카드화 안 돼 가로 넘침, 금액 절단(13,824,/2,9…).
