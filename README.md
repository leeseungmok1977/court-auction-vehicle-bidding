### 📅 매일 자동 갱신 (1개월 이내 입찰예정) — 권장 운영 방식

차종을 고르지 않고 **매각기일이 30일 이내인 전국 자동차 경매 물건 전체**를 매일 자동 갱신합니다.

1. 대시보드 **매일 자동 갱신** 패널에서 `자동 갱신 사용` 체크 + 실행 시각(예: 06:30) + 기간(30일) → 설정 저장
   (앱이 실행 중이면 내장 스케줄러가 매일 그 시각에 목록을 갱신)
2. `[지금 갱신]`으로 즉시 갱신도 가능. 갱신된 물건은 목록에 **미분석**으로 쌓임
3. `[국산차 시세 분석]`으로 국산차에 상세·엔카 시세·입찰가 산정을 일괄 적용
4. 대시보드 **입찰예정(30일)** 카드 또는 목록의 `입찰예정 30일만` 필터로 임박 물건 확인

**앱이 꺼져 있어도 매일 갱신**하려면 Windows 작업 스케줄러에 등록:
- 작업 스케줄러 → 작업 만들기 → 트리거: 매일 06:00 → 동작: [run_daily.bat](run_daily.bat) 시작
- 또는 수동 실행: `python -m web.daily 30` (30일 이내 입찰예정 갱신)

> 목록 갱신은 가볍습니다(페이지 순회만, 상세·시세 없음). 시세 분석은 소량·저속이라 필요한 만큼만 실행하세요.
> 기존 분석 결과·관심·메모는 갱신해도 보존됩니다.

- 데이터는 `data/auction.db`(SQLite)에 저장되어 재실행해도 유지됨.
- 수집은 백그라운드로 돌고, 대시보드가 2초마다 진행률을 갱신 → 완료 시 자동 새로고침.

### 🔎 시세 신뢰도 + 케이카 2차 소스 교차검증

시세는 단순 중앙값이 아니라 **신뢰도(0~100, 높음/보통/낮음)** 를 함께 산출한다 — 표본수·가격분산(CV)·매칭단계(동급→확장)·이상치(IQR)·감정가 정합·트림/세대/연료 확인을 종합.

- **케이카 2차 소스**: SK엔카 단일 소스의 편향을 걸러내기 위해 **케이카**(Playwright 인터셉션, `/bc/search/list/drct`)에서 동급 중앙값을 가져와 교차검증한다.
  - 두 소스가 ±10% 이내 **일치**하면 단일소스 상한(88)을 풀어 신뢰도 상향(최대 96), 크게 벌어지면 **불일치 경고**.
  - **분석·재교정 시 자동으로 함께 조회**(config `kcar_cross_enabled: true`). (모델·연식·연료) 캐시 + 요청 상한(`kcar_max_requests`)으로 부하 통제.
  - 개별 상세에서 **[케이카 2차 소스로 교차검증]** 버튼으로 온디맨드 실행도 가능.
- **실측 검증(백테스트)**: 실제 낙찰가와 대조해 **예상낙찰가**(=시세×과거 낙찰률)와 오차(MAE)를 대시보드에 정직하게 공개.
- **실측 캘리브레이션**: 상세에서 사용자가 확인한 실측 시세를 입력하면 시스템 시세 오차를 기록.

> 케이카 필드매핑 확인/문제 진단: `python run_kcar_discover.py [검색어]` (필요시 `--manual`/`--dom`).

### 🖼️ 사진 비전 분류 + 감정요항 반영

- **사진 정렬(정면·측면·실내)**: 각 물건 사진을 **비전 AI로 분류**해 목록·상세 썸네일을 **정면 → 측면 → 실내 운전석** 순서로 보여준다. 순수 측면/실내 컷이 없으면 있는 차량 사진으로 3장을 채우고, 지적도·지도·서류·명판은 뒤로 보낸다. 선박·중장비 등 **비차량은 정직하게 front=0** 처리.
  - 전용 분류 에이전트(`.claude/agents/photo-classifier.md`) + 몽타주 파이프라인(`src/parse/photo_montage.py`). 결과는 DB `photo_order`에 저장.
  - **증분 실행**(신규 물건만): `python scripts/photo_classify.py prep` → (비전 분류) → `python scripts/photo_classify.py apply`.
  - **사진 없음 = 감가**: 사진 0장 물건은 상한가에서 차감(`config.condition_costs.no_photos`).
  - **⚠️ 동일사건 다물건 사진 혼재**: 한 사건에 물건이 여럿이면 각 물건 폴더에 사건 전체 사진이 섞여 들어온다(형제 물건 파일셋 동일) → 정면·측면·실내가 다른 물건 차량일 수 있어 목록에 **'사진 혼재?' 배지**로 경고.
- **감정요항 반영**: 감정평가 요항을 파싱해 색상·연료·주행거리·검사유효기간·상태(외관손상)를 추출·DB 저장(`inspection_to`·`condition_level`·`condition_flags`) → 목록 **검사경과·외관손상 필터**·검사만료 임박순 정렬, 상태·검사는 상한가 산정에 반영. **없는 정보를 지어내지 않고 '미상'으로 표기**(신뢰 최우선).

### 🎨 디자인 · CSS 빌드

- 디자인 시스템은 [.claude/skills/get-design-system/SKILL.md](.claude/skills/get-design-system/SKILL.md)(GET 브랜드 규격, 새 앱 공통) 기준 — 초기 라이트 명세 [DESIGN.md](DESIGN.md). Tailwind **정적 빌드**(CDN 미사용, 오프라인 안전).
  > ⚠️ arbitrary 클래스(`w-10`·`text-[9px]`·`bg-white/[0.08]`·`tracking-[0.12em]`)는 **재빌드 후에만** 적용되고, `css_v` 캐시버스트는 **서버 재시작** 시 반영된다.
- **화면/클래스(HTML·app.py의 색상맵)를 수정하면** CSS 재빌드 필요:
  ```bash
  npm install          # 최초 1회
  npm run build:css    # web/static/app.css 생성 (변경 후 매번)
  ```
- CSS 변경이 브라우저에 안 보이면 **캐시** 때문 — 서버 재기동 시 캐시버스팅(`app.css?v=…`)으로 자동 무효화되며, 즉시 보려면 **Ctrl+Shift+R**(하드 리프레시).
- 폰트는 self-host(Pretendard 300~700·JetBrains Mono·Material Symbols, `web/static/fonts/`).

**🚀 운영 배포 (라이브)**

**🎯 예측 정확도 대폭 개선 (MAE 26.6% → 8.7%)**
- **핵심**: `예상낙찰가 = 최저매각가 × 유찰버킷 프리미엄`. 낙찰가/시세는 CV 25.9%(불안정)지만 **낙찰가/최저가는 CV 12.7%**(median 1.158) — 유찰로 내려간 최저가가 시장 할인을 이미 반영.
- 프리미엄: 신건 1.0 / 1회 1.13 / 2회 1.17 / 3회+ 1.20(전역 수축) + 시세×1.10 소프트캡. **MAE는 LOO(자기 제외) 정직 측정** — 기존 지표는 '전역 단일 할인율×시세' baseline만 재던 것을 실제 예측 방식으로 교체.
- 상세 **입찰 전략 밴드**(보수적/균형/공격적 · 낙찰확률 25/50/75%)·**소매 차익 분석**도 최저가 기반으로 일치.
