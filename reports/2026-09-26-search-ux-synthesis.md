## 유지되는 것 / 안 되는 것 (확인된 사실)
- **유지**: 상세 ← 버튼·브라우저 뒤로가기(필터·2페이지·스크롤 2227px 까지) · 검색 저장 → 즐겨찾기 → 복귀(159=159) · 퀵 칩·가격대 칩 토글은 다른 조건 보존 · 숫자 일치(옵션 건수 = 총수 = 저장 시 건수 = API).
- **미유지**: 하단 탭·사이드바 `차량목록` 복귀 12/12회 초기화(설계상 그렇다 — 코드에 기억 장치 없음, 그러나 `last_list` 쿠키는 이미 있음) · PC 프레임 F5 → 첫 경로.
- **버그(설계 아님)**: [적용]이 `segment`·`date`·`court`·`promising` 을 버림(88→128, 28→1,316) · 날짜·결과 칩 ✕ 가 전부 초기화 · 활성 칩 5종 줄바꿈(2~3줄).
- **정렬이 이름과 반대**: `매각기일순` 1·2페이지 24건 전부 `매각 종료` · `짧은 주행거리순` 첫 카드가 주행거리 0 인 선박.

## 4자리 합의
1. **가장 불편한 것 = 탭 복귀 초기화**(U1). 3평가자 만장일치 "복귀형으로". 상세 화면에서 그 탭이 활성으로 빛나 "내 목록으로"라고 읽히는데 실제로는 유일하게 상태를 버리는 길.
2. **가장 위험한 것 = [적용]의 파라미터 소실**(U2). 사용자가 하지 않은 조작으로 모수가 바뀌고 무음. P0.
3. **매각기일순은 예정 먼저**(U5). 라벨 변경·`입찰예정` 강제 짝짓기는 차선(모수를 바꾸므로).
- 의견 갈림: `필터 초기화` 가 정렬까지 되돌리는 것 — 디자인 "예측 가능, 유지" / 중고차 "정렬 남겨야" → **바꾸지 않음**으로 판정(UX-7).
