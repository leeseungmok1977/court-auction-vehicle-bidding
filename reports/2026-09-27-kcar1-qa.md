## 남은 것 — 차단 아님(잠재·경미, 확인된 사실)

1. `kcar_age_days` 는 `max(0, …)` 다. 그래서 **미래 시각**의 `kcar_checked_at` 도 나이 0 으로 통과한다(시계 오차·수기 편집 때만 생긴다).
2. `kcar_cross_enabled: "false"` 처럼 **따옴표 문자열**이면 `bool("false")` 가 True 가 되어 켜진다. YAML 의 `false` 리터럴은 정상이다.
3. `recompute_all_market` 의 `kcar_on = kcar.ENABLED and 설정` 에서 `kcar.ENABLED=False` 인 경우에도 '오너 결정으로 중지' 문구를 기록한다. 지금은 상수 True 라 도달하지 않는다.
4. settings 가 `disabled` 인데 설정을 true 로 되돌리면, 첫 실행 전까지 감시가 '중지(의도)'로 남는다(과도기).
