  - → **KCAR-2(산정 입력 단일화)가 재개의 선결 조건**이다. 템플릿은 고치지 않았다.

  - 게이트에 걸린 값은 지우지 않으므로 DB 에 남는다(보존 규칙).

- **문구의 날짜**
  - `ops_health.KCAR_STOP_DATE = "2026-09-27"` 이 '오너 결정으로 중지' 문구의 날짜다.

  - 표본 게이트가 5건이므로 통과한 값은 늘 35% 상한이 걸린다(5/11 = 45% > 35%).
  - 가중식 `min(0.35, kn/(kn+6))` 의 0.35·6 은 여전히 코드 리터럴이다. 외부화는 이번 범위 밖이다.
- **재개 전 선결(범위 밖, 고치지 않음)**
  - qa 가 확인한 케이카 C.4 결함 3건이 남아 있다.
    - 실패한 시도는 요청 상한에 세지 않는다.
    - 3회 연속 실패해도 멈추지 않는다.
    - 메인 문서의 403/429 가 타임아웃에 가려 차단으로 판정되지 않는다.
  - 준법 §12 재검토도 필요하다.
  - 설정만 `true` 로 되돌려도 22일 된 값은 나이·표본 게이트가 막는다(테스트로 고정).
- **일일 리포트**: 서버에 배포하기 전까지는 서버 `config.yaml` 이 `true` 다. 그래서 리포트는 예전처럼 '이상'을 표시한다. 이것이 사실에 맞는 동작이다.
